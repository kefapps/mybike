## Recommended Order

1. `MYB-137` - volume vertical, because the corridor currently reads too flat.
2. `MYB-140` - strong silhouettes, because the scene needs memorable shapes.
3. `MYB-138` - material richness, after the larger forms exist.
4. `MYB-135` - density pass, once the modules are worth repeating.
5. `MYB-136` - variants, when the repeated module families are stable.
6. `MYB-139` - lighting/fog pass, to evaluate the richer scene as a whole.

This order can change if the next goal is a quick visual proof rather than production progression.
