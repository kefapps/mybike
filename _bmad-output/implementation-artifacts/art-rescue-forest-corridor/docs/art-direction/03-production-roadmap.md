# Production Roadmap — Forest Corridor Art Rescue

## Phase 0 — Garde-fous

Objectif : arrêter l’hémorragie d’assets incohérents.

Livrables :

- Art bible v0.
- Manifest tiers/IA.
- Validator Unity assets.
- Workflow captures.
- Grille de scoring visuel.

Décision de sortie : aucune production art sérieuse avant que ces garde-fous existent.

## Phase 1 — Kit propre

Objectif : remplacer les formes placeholder les plus visibles.

Livrables :

- Kit Blender procédural forêt v0.
- Variantes de troncs/racines/roches/fougères.
- Import Unity validé.
- Rapport de budgets.

Décision de sortie : les troncs proches ne lisent plus comme poteaux.

## Phase 2 — Composition route-first

Objectif : enrichir la scène sans perdre la lisibilité de conduite.

Livrables :

- Scatter par bandes.
- Densité contrôlée.
- Captures avant/après.
- Rapport de métriques.

Décision de sortie : le corridor lit comme forêt depuis la route.

## Phase 3 — Matière et mood

Objectif : faire passer l’image du prototype au vertical-slice présentable.

Livrables :

- Pass sol.
- Pass lumière/fog.
- Presets d’ambiance.
- Visual score amélioré.

Décision de sortie : l’image a profondeur, palette et matière.

## Phase 4 — Silhouettes mémorables

Objectif : créer des moments visuels identifiables.

Livrables :

- 3 à 5 setpieces.
- Captures annotées.
- Validation route camera.

Décision de sortie : une capture route a au moins une silhouette forte immédiatement compréhensible.

## Phase 5 — IA contrôlée

Objectif : tester Meshy/Tripo sans polluer la prod.

Livrables :

- 1 prop IA en quarantaine.
- Manifest complet.
- Cleanup Blender.
- Validator OK ou rejet documenté.

Décision de sortie : le pipeline est jugé utile ou non, sans compromettre le reste.
