# Visual Diagnosis — MYB-137 Vertical Volume

## Ce que MYB-137 réussit

MYB-137 réussit son intention limitée : tester plus de volume vertical autour de la route.

Comparé à MYB-114 V4, le corridor est plus enveloppant, la route paraît moins isolée, et les bords ont plus de rythme. La stratégie route-first reste la bonne.

## Pourquoi l’image reste mauvaise

### 1. Les troncs lisent comme des poteaux

Les verticales proches sont trop simples : cylindres droits, diamètre uniforme, peu ou pas de rupture de silhouette, pas de base crédible. Un arbre n’est pas juste un tube marron qui a réussi son permis de construire.

Correction :

- bases évasées ;
- troncs cassés ;
- torsions ;
- racines qui s’intègrent au sol ;
- branches basses ou cicatrices ;
- variations nettes de hauteur et diamètre.

### 2. Le sol ne raconte rien

Le sol est trop uniforme. Il manque la micro-composition stylisée : feuilles, mousse, terre exposée, racines, cailloux, transitions route/berme.

Correction :

- patches de feuilles/mousse géométriques ;
- lignes de racines basses ;
- rochers semi-enterrés ;
- bermes plus sculptées ;
- variations de teinte par bande.

### 3. Le fog est une nappe grise, pas un outil de composition

La profondeur devrait séparer foreground, midground et background. Ici, le fog a tendance à aplatir la scène.

Correction :

- fog moins uniforme ;
- couleur plus dirigée par palette ;
- silhouette line sombre au midground ;
- arrière-plan plus doux, pas identique partout.

### 4. Il manque une canopée

La scène a des troncs, mais peu de masses hautes. Une forêt sans canopée donne une impression de terrain après coupe rase.

Correction :

- masses de canopée stylisées en arrière-plan ;
- branches hautes simplifiées ;
- silhouettes de pins/sapins lointains ;
- ombres portées ou bandes de valeur.

### 5. Pas de moments mémorables

La route avance, mais rien ne crée de “moment” : arbre penché, souche géante, tronc tombé, arche de racines, rocher moussu.

Correction :

- 3 à 5 setpieces visibles ;
- placer à distance route contrôlée ;
- pas d’obstruction ;
- silhouettes validées depuis la caméra route.

## Verdict

MYB-137 est un bon proof technique de verticalité. Il ne doit pas être considéré comme une passe de qualité finale. La suite doit viser la hiérarchie visuelle, pas juste l’augmentation du nombre d’objets.
